# Ses Sinyali Analiz Aracı

Python ile geliştirilmiş bir ses sinyali analiz aracı. Bir .wav dosyasını
okuyup dalga formu, frekans spektrumu (FFT), filtreleme ve spektrogram
analizleri yapar.

## Özellikler
- Dalga formu görselleştirme
- FFT ile frekans spektrumu analizi
- Alçak geçiren (low-pass) filtre uygulama
- Spektrogram (zaman-frekans analizi)

## Kurulum
```bash
pip install numpy scipy matplotlib
```

## Kullanım
```bash
python analiz.py
```

## Kullanılan Kütüphaneler
- NumPy
- SciPy
- Matplotlib
